How to use it on your iPhone

  1. Host this folder on GitHub Pages.
  2. Use a LiDAR scanning app that can export an OBJ or PLY mesh.
  3. Open this GitHub Pages link in Safari and choose the exported file.
  4. Adjust the tolerance and slope, then select Extract ground.
  5. Export the ground mesh for use in a 3D editor or mapping workflow.

This is a mesh post-processor, not a live LiDAR scanner. Dense plants may hide the actual ground, and those missing surfaces cannot be inferred reliably from a single mesh.
